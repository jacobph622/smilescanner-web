Which device is this?

    No browser reports a screen's true physical density, so the target has to be told which panel it is drawing on. Pick the model once and every dimension on the board is exact. Tap the ppi figure later to fine-tune it.

    On iPhone and iPad, leave Settings → Display & Brightness → Display Zoom on Default. Picking the model handles Larger Text correctly, but changing the setting later changes the scale, so reload if you do.
